# Архимаг кода — дизайн сайта школы программирования для детей

**Концепт · 2026 · современный интерактивный лендинг + живая база отзывов + PostgreSQL и админ-авторизация**

Сайт построен на идее «академии цифровой магии»: код — это заклинания, проекты — артефакты, группы — гильдии, прогресс — мана. Визуально это смесь футуристичного интерфейса и магической атрибутики в глубоких синих тонах.

## Как открыть

| Способ | Что работает |
| --- | --- |
| **Через `server.py` / живое превью на порту 8001** (рекомендуется) | Полный функционал: форма отзывов и заявок пишет в SQLite или PostgreSQL, лента обновляется автоматически, админка показывает реальные таблицы и защищена паролем на публичном деплое, CSV экспортируется с сервера |
| `index.html` + `styles.css` + `app.js` через любой HTTP-сервер | Модульная версия для разработки и хостинга; файлы должны лежать рядом |
| `index-standalone.html` двойным кликом / в просмотрщике Arena | Один файл со встроенными стилями, скриптами и картинками: дизайн и интерактив работают везде, отзывы сохраняются в браузере (демо-режим «Демо · локально») |

Проект существует в **двух видах**: модульная версия (`index.html`, `styles.css`, `app.js`, `assets/`) — основная для сервера и деплоя, и самодостаточная копия `index-standalone.html` — для быстрого просмотра без сервера и для песочниц вроде просмотрщика Arena (там внешние CSS/JS не загружаются).

## Запуск у себя на компьютере

Нужен **Python 3.9+**. Для локального запуска с SQLite достаточно стандартной библиотеки — `pip install` не нужен. Для PostgreSQL установите зависимости: `pip install -r requirements.txt`. Скопируйте к себе всю папку `archimag-code`.

| ОС | Один клик | Из терминала |
| --- | --- | --- |
| Windows | двойной клик по `start-windows.bat` | `python server.py 8001` |
| macOS | двойной клик по `start.command` | `./start.sh` или `python3 server.py 8001` |
| Linux | `./start.sh` в терминале | `python3 server.py 8001` |

Лаунчер сам найдёт Python, откроет браузер и выведет адрес. Затем откройте **http://localhost:8001/** (именно `localhost`, не `0.0.0.0` — это адрес привязки сервера). Остановить сервер: **Ctrl+C** в окне терминала.

Если порт 8001 занят, передайте другой: `python3 server.py 8080` (или `start.sh 8080` / `start-windows.bat 8080`).

Для модульной версии нужны: `index.html`, `styles.css`, `app.js`, `assets/`, `server.py`, `database.py`, `schema.sql`, `schema_postgres.sql` (вторая — только при `DATABASE_URL`). Папка `data/` и база `data/reviews.db` создаются автоматически при первом запуске; `index-standalone.html`, `preview/`, `tokens.css`, `DEPLOY.md` и этот README — дополнительные материалы.

### Если Windows ругается на `.bat`

`start-windows.bat` специально написан **только латиницей и с переводами строк CRLF**: `cmd.exe` некорректно читает кириллицу в UTF-8 и Unix-окончания `
`, из-за чего появляются ошибки вроде `'ul' is not recognized` или `'ttps:' is not recognized`. Если такой файл уже скачан — замените его свежим из архива.

Альтернатива без лаунчера: откройте «Командную строку» в папке проекта и выполните:

```bat
python server.py 8001
```

Затем откройте `http://localhost:8001/` в браузере. Это самый надёжный способ, он не зависит от кодировки `.bat`.

Если просто открыть `index.html` двойным кликом **без сервера**, дизайн и интерактив работают, но отзывы сохраняются в браузере (демо-режим) — для настоящей базы данных нужен запущенный `server.py`.

## Где будет доступен сайт

| Сценарий | Как открыть | Ограничение |
| --- | --- | --- |
| Только этот компьютер | `http://localhost:8001/` | Работает, пока запущен `server.py` |
| Телефон/планшет в той же Wi‑Fi | Узнать IP командой `ipconfig` (Windows) или `ip addr` (Linux/macOS), открыть `http://192.168.1.42:8001/`, разрешить Python в брандмауэре | Сервер уже привязан к `0.0.0.0`; компьютер должен быть включён |
| Временная ссылка из интернета | `ngrok http 8001` или `cloudflared tunnel --url http://localhost:8001` | Публичный HTTPS-адрес живёт, пока работает компьютер и туннель |
| Постоянно, откуда угодно | **Render Free + Neon Free PostgreSQL** (см. [DEPLOY.md](DEPLOY.md)) | Бесплатный Web Service засыпает через 15 мин простоя; пробуждение ≈1 минута |
| Только макет, без базы | Загрузить `index-standalone.html` (переименовав в `index.html`) на Netlify / GitHub Pages / Vercel | Отзывы сохраняются в localStorage, SQLite не используется |

**Два режима запуска.** Локально (без переменных) — SQLite в `data/reviews.db`, админка открыта без пароля. Для публикации задайте `DATABASE_URL=postgresql://…` — подключится **PostgreSQL**, а просмотр контактов, удаление и выгрузка CSV будут доступны только после входа в админку. Полная бесплатная инструкция: **[DEPLOY.md](DEPLOY.md)**.

| Переменная | Назначение |
| --- | --- |
| `PORT` | Порт; хостинги задают его автоматически |
| `DATABASE_URL` | Строка подключения к PostgreSQL; включает общую БД и авторизацию |
| `ADMIN_USER` / `ADMIN_PASSWORD` | Логин и пароль админки (обязательны в продакшене) |
| `SESSION_SECRET` | Секрет подписи cookie; **одинаковый на всех инстансах** |
| `COOKIE_SECURE` | `1` для HTTPS |
| `REQUIRE_AUTH` | `1` включает авторизацию и при локальном SQLite |

Запуск: `python3 server.py 8001` или `PORT=8080 python3 server.py`. Для PostgreSQL установите `pip install -r requirements.txt`. На VM можно взять `Dockerfile`; для Render есть `render.yaml`, для Heroku-совместимых платформ — `Procfile`.

**Если фронтенд и API на разных доменах:** перед подключением `app.js` задайте `window.ARCHIMAG_API_BASE = 'https://api.example.com/'` — тогда запросы и экспорт CSV пойдут на этот адрес. По умолчанию используются относительные `api/...` (один сервер). API уже отдаёт `Access-Control-Allow-Origin: *`.

**Несколько инстансов.** PostgreSQL — общая база для всех процессов; схема применяется через `CREATE TABLE IF NOT EXISTS`, а стартовые данные защищены `pg_advisory_xact_lock`. Сессия админки — подписанная HMAC-cookie (stateless): состояние на сервере не хранится, поэтому вход действует на любом инстансе с тем же `SESSION_SECRET`. SQLite остаётся удобным локальным режимом для одного процесса.

## Экраны

1. **Hero** — кинематографичный арт академии, заголовок и «гримуар»: интерактивная консоль с тремя языками (Scratch / Python / JavaScript). Кнопка «Произнести заклинание» запускает анимированный рунный круг и вспышку частиц на canvas.
2. **Направления** — 6 курсов с фильтром по возрасту (7–9 / 10–12 / 13–16) и модальным окном программы с syllabus.
3. **Как проходит урок** — переключаемые 4 этапа урока с панелью деталей и шкалой «маны».
4. **Кодекс архимага** — мини-игра: нужно нажать строки кода в правильном порядке, чтобы открыть портал. Неверный порядок даёт `SyntaxError`.
5. **Живые отзывы** — лента из базы данных: фильтр по курсу, сортировка (новые / оценка / лайки), лайки, подсветка нового отзыва и автоматическое обновление раз в 5 секунд. Кнопка открывает форму отзыва.
6. **Пробный урок** — CTA-блок с портальным артом и форма заявки.
7. **База данных** — отдельный экран админ-панели: статистика, таблицы `reviews` и `leads`, поиск, фильтры, удаление, экспорт CSV, схема SQL и список API-методов.

## База данных

Один слой данных (`database.py`) работает с **двуми движками**:

| Режим | Где лежат данные | Схема | Когда использовать |
| --- | --- | --- | --- |
| SQLite | `data/reviews.db` | `schema.sql` | Локальный запуск, один процесс, ноль зависимостей |
| PostgreSQL | внешняя БД из `DATABASE_URL` | `schema_postgres.sql` | Публичный деплой, несколько инстансов |

| Таблица | Поля | Назначение |
| --- | --- | --- |
| `reviews` | `id, author, role, course, rating, text, likes, status, created_at` | Опубликованные отзывы |
| `leads` | `id, parent, child, age, course, contact, created_at` | Заявки на пробный урок |

При первом запуске база наполняется 8 демонстрационными отзывами и 3 заявками — чтобы лента и админка были непустыми. Схема в `schema.sql` для SQLite и `schema_postgres.sql` для PostgreSQL; всё, что добавите через формы после этого, записывается по-настоящему.

### REST API

| Метод | Путь | Действие |
| --- | --- | --- |
| GET | `/api/health` | Движок, число записей, флаг авторизации |
| GET | `/api/reviews` | Отзывы; параметры `course`, `q`, `sort` |
| POST | `/api/reviews` | Создать отзыв |
| POST | `/api/reviews/:id/like` | Лайк |
| DELETE | `/api/reviews/:id` | Удалить отзыв · **только админ** |
| POST | `/api/leads` | Создать заявку (публично) |
| GET | `/api/leads` | Список заявок · **только админ** |
| DELETE | `/api/leads/:id` | Удалить заявку · **только админ** |
| GET | `/api/stats` | Средний рейтинг, распределение по курсам |
| GET | `/api/export.csv` | Выгрузка CSV с BOM · **только админ** |
| GET | `/api/admin/session` | Состояние сессии |
| POST | `/api/admin/login`, `/api/admin/logout` | Вход и выход |

**Защита и валидация:** длина и обязательность полей, `rating` 1–5, `age` 6–18, проверка курса по белому списку, honeypot-поле, лимит 6 записей в минуту с одного IP, экранирование на клиенте, запрет прямой отдачи `.db` файла. Публичные формы (отзыв, лайк, заявка) открыты всем; просмотр контактов, удаление и выгрузка CSV требуют входа. Пароль сверяется через `compare_digest`, cookie подписана HMAC-SHA256, `HttpOnly` + `SameSite=Lax` (+ `Secure` на HTTPS), срок жизни 12 ч. В локальном SQLite-режиме авторизация выключена для удобства.

## Два режима работы

При загрузке страница пробует `/api/health`:

- **Есть сервер** → `SQLite · LIVE` или `PostgreSQL · LIVE`: отзывы, лайки, заявки и удаление идут через API; каждые 5 секунд лента синхронизируется, новый отзыв появляется с уведомлением. На публичном деплое админка закрыта формой входа.
- **Нет сервера** (открыт файл, просмотрщик Arena) → `Демо · локально`: те же сценарии работают на `localStorage` (с фолбэком в память, если хранилище недоступно), экспорт CSV собирается на клиенте. Интерфейс честно показывает режим.

## Границы концепта

Дизайн проверен в headless Chromium на 1440×900 и 390×844: ошибок в консоли нет, якоря и адаптив работают. Метрики, тексты курсов и стартовые отзывы — демонстрационные. Авторизация админки и PostgreSQL для нескольких инстансов реализованы. Нет модерации, настоящей отправки e-mail и платёжного модуля; rate limit пока хранится в памяти процесса, CAPTCHA и миграции — для настоящего продакшена.
